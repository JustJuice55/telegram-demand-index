[![Daily update](https://github.com/JustJuice55/telegram-demand-index/actions/workflows/update.yml/badge.svg)](https://github.com/JustJuice55/telegram-demand-index/actions/workflows/update.yml)

[![Code: MIT](https://img.shields.io/badge/code-MIT-green)](LICENSE)
[![Source: tgden.com](https://img.shields.io/badge/source-tgden.com-2aabee)](https://tgden.com/en?utm_source=github&utm_medium=referral&utm_campaign=demand-index)

Telegram is where people ask for a taxi in Dubai, a truck out of Tashkent, a flat in Phuket or
a plumber in Moscow. Those requests sit in tens of thousands of city and community chats that
no search engine reads. [tgden](https://tgden.com/en?utm_source=github&utm_medium=referral&utm_campaign=demand-index)
reads them every day; this repository publishes the count.

**Why it is useful.** In a freelancer chat a hundred sellers answer every request and the buyer
picks from a queue. In a chat about renting in Dubai there may be one. The index shows where
people ask and how much, so you can see which markets are crowded and which are not.

## Data

| File | What is in it |
|---|---|
| [`data/latest.csv`](data/latest.csv) | One row per country × niche: requests in 7 and 30 days, share of the country, top chats, page on tgden.com |
| [`data/latest.json`](data/latest.json) | The same index exactly as the API serves it |
| [`data/history/`](data/history/) | One snapshot per day, so you can follow a market over time |

The same data is live, free and keyless:

```bash
curl -s https://tgden.com/api/v1/intent/week | jq '.items[] | select(.country=="ae")'
```

AI agents can ask for it through the remote MCP server at `https://tgden.com/api/mcp`
(tool `telegram_demand`). See [tgden-api](https://github.com/JustJuice55/tgden-api).

## Method

- **A request** is a unique message text in a public Telegram chat in which someone asks to buy,
  rent, hire or ship something. It passes the same filter tgden uses for paid leads: ads,
  sellers, bots and mass mailings are dropped.
- A repost counts once, in the week it was last posted. Counts are requests, **not unique people**.
- The country comes from the request itself, otherwise from the chat.
- Only public chats are read. No message text, phone number or personal account is published here.

**Compare shares, not raw counts.** The reader covers more chats from week to week, so absolute
numbers grow with coverage, not only with demand. A niche's share of all requests in its country
is the figure to compare between weeks; the history folder lets you check it yourself.
